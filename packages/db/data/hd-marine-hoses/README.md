# Hydraulics Direct batch 7 — `hd-marine-hoses`

**20 listings, 638 part numbers** of marine hose from Hydraulics Direct's catalogue (a third-party
marine-hose brand there), listed **unbranded** under `IH-MH-<supplier part>` in a new
`marine-hoses` category under Industrial Hoses, with the `industrial-hose-spec` template.

- Wet exhaust & water (soft wall, hard wall, silicone, corrugated), EPDM heater and water hose,
  bilge/live-well/water-fill hose, potable PVC tubing, and fuel hose (Type A1-15, A2, B1-15).
- One row per size and supply form (box, coil, reel, cut length, cut length with clamps); the new
  `supply` text column (`@indus/domain` variant-columns, PR #481) shows it, and the description lists
  supply by size meanwhile. Rows carry `hoseDash`/`hoseInch` for the Hose bore column.
- Standards and approvals (SAE J2006, SAE J1527, ISO 7840, ABYC, USCG types, Lloyd's) are quoted as
  the manufacturer states them; working pressure only where the source's part names give it.
- "Above the waterline only" usage limits from the source are on each page that has one.
- Dropped: 36 silicone-hose `-S/S` rows (meaning not stated). Bilge rows carry colour (white/black).
- Images: 9 unbranded cutaway images used; the other 11 show the maker's brand printed on the hose
  and are not used.
