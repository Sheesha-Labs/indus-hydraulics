# Hydraulics Direct batch 11 — `hd-weld-on-adapters`

**12 listings, 122 part numbers** of weld-on (weld-to-thread) adapters for tube and metal hose,
unbranded:

- 7 × forged 316 stainless (`IH-PF-SS-WO-*`) and 1 × cast 304 stainless (`IH-PF-CWO-B4-MP`)
  into the existing `stainless-steel-weld-outlets` category, next to the weld-on BSPP swivel
  from batch 4 (category left untouched: empty `bands`).
- 4 × zinc-plated carbon steel (`IH-ST-WO-*`) in a new `steel-weld-on-adapters` category
  under Hydraulic Adapters (position 26).

Ends: ORFS/JIC 37° female swivel (straight, 45°, 90°), JIC 37° male, NPT male/female.
`SS-WO-FFX` and `SS-WO-FJX45T` carry a tube-O.D. and a pipe weld bore per size; which code is
which differs between the two families, so labels follow each source name. `SS-WO-FJX45T-24-24`
is named 1/2" in the source; the code and size filter say 1-1/2". No pressure ratings
published. No image on `SS-WO-FFX`, `WO-FJX`, `WO-MJ` (brand on hex).
The source lists the flange and weld-on families twice (two menus, identical data); batch
scripts now pick families by id.
