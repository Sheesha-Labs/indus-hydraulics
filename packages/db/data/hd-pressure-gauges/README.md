# Hydraulics Direct batch 15 — `hd-pressure-gauges`

**3 listings, 51 part numbers** of 2-1/2" glycerin-filled pressure gauges (stainless case and
bezel, brass internals, polycarbonate lens, ASME B40.100), unbranded `IH-GA-*`, into the
existing `ic-pressure-gauges` category (left untouched): bottom mount (28 ranges), centre
back mount (17), front-flange panel mount (6). Vacuum, compound and 0–15 to 0–15,000 psi.

The source names give "1/4" Lower Mount" with no thread; pages say the thread is confirmed
with the quotation. Range labels feed the new `Range` size-table heading (PR #481).
