## Rows and columns

Rows are `IH-BD-<Bijur Delimon part number>`; each family page carries its units, accessories and service parts, units
(parts with published data) first. Columns are the lubrication text columns added in #555 (`systemType`, `lubricant`,
`reservoir`, `voltage`, `output`, `maxPressure`, `outletThread`, `monitoring`, `container`) plus the existing `ports`
(oil / fluid / air inlets). Oil circulating units carry motor kW, number of pumps, filter and size in the `item` text —
there is no column for them.

`systemType` is left off single-point, OCS, rail and enclosure listings: Bijur tags OCS units "SLR" and LubeSite feeders
"SP", which read as false claims on those pages. Seven order-code families (AV/AVE/AVH, AirMax, OSG, OSM, PLA, ONL, SDU)
carry the same order-code table as wave 1.

Left out on purpose: two customer-named kits (an end user's name is in the Bijur description) and two rows Bijur lists
as "#N/A".

## Images and documents

`indus-jpeg-special/`), checked on a contact sheet. The unit leads each gallery: the configurator photo where the unit is
sold by order code, otherwise the part with the most published data. DVA/DVU flowmeters have no photo — Bijur's site
shows only a "Product Photo Coming Soon" placeholder (2,285 of the export's series images are that placeholder; none is
used). Documents (`data/bijur-delimon-documents-special-lubrication`): one datasheet per listing that names the series,
plus manuals; 26 attachments, 23 PDFs.
