## How to re-run

The 211-product import takes ~5-10 minutes against the remote pooled DB. **Use the direct URL (port 5432, NOT pgbouncer 6543) for the bulk import** to avoid pgbouncer transaction-pool slot exhaustion. The `INDUS_IMPORT_TIMEOUT_MS` env var lets you bump Prisma's transaction timeout (default raised to 15 minutes by this batch's CLI tweak).

```sh
DATABASE_URL=$(grep -E '^DIRECT_URL=' packages/db/.env | sed 's/^DIRECT_URL=//' | tr -d '"') \
  pnpm --filter @indus/db db:import src/imports/2026-05-07-adapters.ts --dry-run
```

## Notes for editors

- **Spec values are inferred from product titles**, not from per-product engineering datasheets. Pressure / size defaults are the SAE / DIN / ISO industry baselines per family (e.g., DIN 2353 L-series → 250 bar, S-series → 400 bar; BSP → 400 bar; JIC → 350 bar). The PDP description and FAQs explicitly call this out: "rated to host port grade — confirm with Indus engineering for safety-critical applications". Edit per-product values in admin if you have datasheet specifics.
- **Three duplicate names from the source Excel** were disambiguated with "(Variant 2)" suffix:
  - DIN 2353: "Adjustable BranchTee" (×2), "Bulkhead Elbow Union Metric" (×2)
  - BSP: "Thread Reducer" (×2)
  Update titles in admin if you'd like richer disambiguation (e.g., reference the actual thread mix).
- **"Hydraulic SAE Flanges" sub-category** also includes 2 spare-parts items per the source Excel: "O-Rings for SAE Hydraulic Flanges" (`IH-AD-HSF-009`) and "Set of Bolts and Spring Washers" (`IH-AD-HSF-010`). Both have `body_configuration: 'accessory'` so the spec table reflects that they're parts, not flanges.
- **CLI change in this PR:** `packages/db/src/import/cli.ts` had its hard-coded Prisma transaction timeout (300_000 ms) replaced with an env-overridable default of 900_000 ms (15 min). This was needed because 211 products × 9-13 specs × 8 FAQs hits ~4,000 individual row operations and exceeds 5 minutes against the pooled DB. Future bulk batches can extend further via `INDUS_IMPORT_TIMEOUT_MS=1800000` etc.
