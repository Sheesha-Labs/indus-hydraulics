## Notes for editors

- **Megamenu nav rows have new IDs.** Because `replacePlaceholderLeaves`
  delete-and-recreates the children of the matched sub, the NavMenuItem rows
  for Crimp Ferrules / Metric / DIN have new database IDs after this import.
  The labels and category links are unchanged — only the IDs differ. This
  has no user-visible effect; mention only if someone has bookmarked the
  admin nav editor with old item IDs.

- **Brand and category core fields** (`isAuthorizedDistributor`, `country`,
  `parentId`, `defaultSpecTemplateId`, `position`, `isPublished`) remain
  editable only via the inline modals on `/admin/brands` and
  `/admin/categories` — the dedicated `/[id]/edit` pages are SEO-only.
