## Library improvement (also in this PR)

`packages/db/src/import/navigation.ts` — extended `replacePlaceholderLeaves` with two new optional config fields:

- `createSubSectionIfMissing: boolean` (default `false`) — when `true` and the named sub-section doesn't exist under the column, the helper auto-creates it as a `linkType: 'custom_url'` heading row mirroring the seed-time pattern (`/c/{column-slug}?sub={kebab-of-label}`).
- `newSubSectionPosition?: number` — explicit position among siblings; defaults to appending after existing siblings.

This unlocks adding brand-new product families to the megamenu in a single import (instead of needing a separate manual nav edit). Existing imports are unaffected — both new fields are optional and default to the previous behaviour.

## Notes for editors

- **Material:** all 53 products use `316L stainless steel (austenitic, low-carbon, marine grade)` for the Material spec, and `Passivated 316L (no plating; native corrosion-resistant oxide layer)` for Surface Treatment. This is the load-bearing distinction from the existing carbon-steel hose fittings.
- **Spec values are inferred from product titles**, like prior batches. Confirm specifics against engineering datasheets when admin staff have them; especially for the 4 "SAE Flanges for Hoses" products where mapping to `sae-flange-spec` is approximate (counter-flange and seal-set use `configuration: clamp-only` as the closest fit).
- **No SS316L crimp ferrules are part of this batch.** Customers ordering SS316L hose fittings will be asked to specify their hose grade so we can recommend the matching SS316L crimp ferrule (separate batch when those land).
- **Operating temperature** is wider than carbon-steel fittings (-40°C to +200°C vs +120°C) — but limited by the elastomer in any face-O-ring or dynamic seal.
