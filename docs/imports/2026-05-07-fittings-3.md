## Notes

- **NPT vs BSPT** — NPT (60° thread angle, ASME B1.20.1) and BSPT (55° thread angle, ISO 7/BS 21) are NOT interchangeable despite both being tapered pipe threads. The `npt-npsm-sae-hose-fittings` category contains NPT only; BSPT taper male lives in `bsp-hose-fittings` (`IH-BSP-MAL-T`, from PR #66).
- **Code 61 vs Code 62** — Code 62 split-flange clamps and flange-on-fittings are NOT interchangeable with Code 61. Different bolt patterns and different pressure ratings (210 bar vs 415 bar). The `sae-flange-spec` template's `flange_code` field captures this.
- **"Supercat"** — one-piece flange-and-fitting design (vs separate flange + threaded fitting). Treated as Code 62 high-pressure for this batch.
- **Megamenu nav rows have new IDs** — the existing 6 leaves under "Hose Fittings" are delete-and-recreated. Labels and category links unchanged; user-visible behaviour identical.
- **Brand and category core fields** remain editable only via inline modals on `/admin/brands` and `/admin/categories` list pages.
